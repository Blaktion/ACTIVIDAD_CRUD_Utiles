# 📚 Sistema de Gestión de Inventarios - Útiles Escolares

¡Bienvenido! Este es un proyecto desarrollado para la asignatura de **Programación**. Consiste en una aplicación web tipo CRUD (Create, Read, Update, Delete) que permite administrar de forma eficiente el inventario de una papelería o almacén escolar.

## 🚀 Características principales
* **Gestión Completa:** Permite agregar, listar, editar y eliminar productos.
* **Cálculo Automático:** El sistema calcula el valor total del inventario en tiempo real.
* **Campos Personalizados:** Inclusión de campos específicos como *Marca* y *Precio Unitario*.

## 🛠️ Tecnologías utilizadas
* **Backend:** Python 3.x con el micro-framework **Flask**.
* **Control de Versiones:** Git y GitHub.
